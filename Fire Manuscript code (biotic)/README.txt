READMELong-term annual growing-season fire reduces plant diversity and homogenizes soil fungal communities in a longleaf pine savanna Authors: Michelle Henson, Lisa Giencke, Yan Yi (Anny) ChungDescription: This repository contains processed data, metadata, and R scripts associated with the manuscript examining the effects of prescribed fire frequency on plant, fungal, and bacterial communities in longleaf pine ecosystems.Repository Structuredata/Processed abundance tables, taxonomy tables, and environmental datasets used in analyses.metadata/Sample metadata and plot level environmental variables.scripts/R scripts used for statistical analyses, community analyses, and figure generation.figures/Output figures associated with the manuscript.Sequence DataRaw sequencing reads are available through the NCBI Sequence Read Archive (SRA) under accession number: PRJNA1469031SoftwareAnalyses were conducted in:RQIIME2 version 2022.11NotesScripts were organized by community type:Fire manuscript code_2026.RContains: bacterial community analyses (16S), fungal community analyses (ITS), and plant community analyses in manuscriptFire manuscript code_2026 only soil.RContains: soil nutrient analysis in manuscript
